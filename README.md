# 🌐 Simulasi Jaringan Komputer UPN "Veteran" Yogyakarta (Desain 2025)
Dokumentasi dan simulasi perancangan infrastruktur jaringan komputer terintegrasi untuk kampus UPN "Veteran" Yogyakarta berbasis Cisco Packet Tracer, disesuaikan dengan kebutuhan estimasi denah dan kapasitas gedung pada tahun 2025.
📌 Gambaran Umum (Project Overview)
Proyek ini bertujuan untuk merancang topologi jaringan skala menengah hingga besar (Enterprise Campus Network) yang andal, aman, dan dapat diskalakan (scalable). Simulasi mencakup penataan antargedung di lingkungan kampus (seperti Gedung Rektorat, FTI, FEB, FISIP,  dan Fasilitas Umum) menggunakan pendekatan Hierarchical Network Design (Core, Distribution, dan Access Layer).
